# AGENTS.md — 數學慢慢懂 ## 1. 專案目的 建立一個可持續擴充的高中數學重點整理網站。 提供以下功能： - 高中數學觀念整理 - 常用公式與定理 - 例題逐步詳解 - 互動式小測驗 目標是讓 AI 依照既定規則，快速增加新章節。 ## 2. 網頁風格 - 主題：簡約、溫暖的學習筆記網站 - 主色：深綠色 #277c65 - 背景色：奶油白 #fbfaf6 - 使用圓角卡片展示數學章節 - 所有內容使用繁體中文 - 必須支援手機及電腦瀏覽 ## 3. 頁面結構 首頁： - 網站標題與介紹 - 章節分類功能 - 搜尋功能 - 數學章節卡片 每個數學章節包含四頁： 1. 核心觀念 2. 必背公式 3. 例題詳解 4. 隨堂小測驗 ## 4. 檔案結構 專案根目錄： - index.html：網頁與互動程式 - AGENTS.md：AI 開發規範 - README.md：專案說明（可新增） 網站使用 HTML、CSS、JavaScript。 不需要資料庫或後端。 ## 5. 新增內容規範 新增數學章節時： 1. 在 chapters 陣列新增資料。 2. 每個章節需要唯一的 id。 3. 必須填寫章節名稱及分類。 4. 必須包含觀念、公式、例題及測驗。 5. 所有例題需提供完整計算過程。 6. 測驗必須附上正確答案及解析。 7. 新增分類時同步修改 categories 陣列。 8. 更新首頁顯示的章節數量。 ## 6. AI 開發規則 AI 修改專案時必須： - 先閱讀 AGENTS.md。 - 保留原有網站的視覺風格。 - 優先使用既有的頁面模板。 - 不可任意刪除已完成的章節。 - 不可破壞搜尋、分類、翻頁及測驗功能。 - 確認數學公式及計算答案正確。 - 保持網頁可在 GitHub Pages 正常使用。 ## 7. 完成前檢查 每次修改後檢查： - 首頁可以正常顯示。 - 所有章節可以開啟。 - 可以切換前後頁。 - 測驗答案判斷正確。 - 搜尋及分類正常。 - 手機版排版沒有溢出。 - GitHub Pages 可以正常瀏覽。 ## 8. 未來擴充方向 未來可以新增： - 一元二次方程式 - 多項式 - 向量 - 直線與圓 - 空間幾何 - 統計 - 積分入門 所有新增章節都必須遵循相同架構。
